## Licence handling

Checked against the LFM2 determination above (`decision_class` informational; binding condition `commercial-use-limitation` with `agreement_required: false`).

- **Terms ship as a notice and are not waived.**
  - The licence text `4d28ca14…` ships in the archive and in the carrier.
  - The commercial-use clause (the "Threshold" definition and section 5) is present in `LICENSE-LFM.txt`.
  - The notes, README, carrier `DELIVERY` and release record say the terms are a notice, are not waived, and that no agreement is recorded.
- **Nothing accepts terms for the user.** kilix-license `capture_agreement` returns decision `record` with no typed text for an informational record, and raises if typed text is supplied. Both callers keep to that:
  - The OS migration (`_migrate_command_model`) calls it only after checking `expected_decision == 'record'`. Otherwise it returns not-migrated with "its terms need a typed agreement, which an upgrade never answers".
  - Kilix `content_models._install` asks for a typed accept only when `expected_decision == "accept"`.

  No code read here answers an agreement prompt.
- **Kilix first-use download.** The launcher calls `config/kilix_ask_offer.py` only at a terminal, without `--yes`, and only when Needle reports `grammar not-installed`. The flow is:
  1. A wizard "no" is saved as the grammar selection and nothing is asked.
  2. Otherwise the offer asks `[y/N]`. Yes runs `content_models.py ensure lfm2-kilix-commands`.
  3. `ensure` prints the plan and the licence authority's first-use screen, then asks `Install this exact model in the shown root? [y/N]`.
  4. The receipt is written through `first_use.install_with_agreement` with `typed_text=None`, so it records the notice and claims no agreement.

  Without a terminal, `ensure` raises before any download.
- **OS v9-to-v10 migration.** `provision/install-image-models.py` `migrate_command_model` runs in the desktop-user upgrade step and in the fresh-install `--offline` call, unattended and with no network. It:
  1. returns before opening licence records or the receipt store when the pinned catalog differs from the pin (fixed by `102b7d1`);
  2. requires the v9 directory `lfm2-kilix-commands--ef701ec2…` and a receipt that covers record `e4d08e2c…` for the v9 manifest;
  3. checks every v10 file against the v9 files before writing a receipt;
  4. writes the notice receipt for the v10 manifest only for records not already covered;
  5. installs through `ensure_supplied_asset`, and withdraws the receipt it wrote if that fails (see finding N1 for one exception).
- **Kilix-only machine with v9.** Needle reports `grammar not-installed`. The offer says an earlier delivery is on disk and will be reused. After yes, the licence screen asks its own `[y/N]`, and the Content installer's `_populate_upstream_or_earlier` stages v10 from the installed v9 directory, verifying every file, before any download. The offer itself is asked once. A new v10 notice receipt is recorded. As briefed, the owner confirmed on 2026-11-16 that this is intended.
