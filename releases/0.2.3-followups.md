# Plebian-OS 0.2.3 follow-ups

## F104 speech and Voicebox qualification

On 2026-10-30 the release owner retained completed fixes for 0.2.2 and deferred
the remaining F104 work to 0.2.3. F104 is not qualified by this deferral.
This record does not change unrelated release gates or select additional models.

- Freeze supported CPU and GPU profiles, exact source and runtime dependencies,
  and numerical quality, latency, real-time, memory and timestamp budgets.
  Resolve the unmet Qwen real-time requirement before advertising that capability.
- Complete synthesis language, built-in voice, consented clone and voice-design
  coverage. Extend transcription evidence with reference timestamp error,
  candidate comparisons and every advertised output and language mode.
- Complete a four-hour mixed-job soak without interference from separate test
  clients. Retain failed attempts, per-job results, memory observations and
  evidence that owned workers and device grants are released.
- Complete cancellation during inference, deadline and disconnect handling,
  worker crash, OOM, device loss, corrupt inputs, disk exhaustion and restart
  checks. Verify cross-client isolation, queue bounds and resource sharing.
- Complete microphone exclusivity, recording indicators, screen-lock and
  disconnect termination, and device recovery on supported hardware.
- Finish installed Voicebox generation, long jobs, cancellation, history,
  playback, consented sample export/deletion, and tab lifecycle checks.
  Preserve profile create/import/export and transcription evidence already obtained.
- Finish model-install interruption, corruption, quota and in-use removal
  controls, plus fresh OS installation, supported upgrade, dependency closure,
  offline operation and rollback with user data preserved.
- Obtain independent privacy/security and final qualification acceptance on
  the frozen source, model and runtime versions.

The completed 0.2.2 fixes include order-independent validation of all selected
Qwen model bindings and the optional Voicebox producer's selected dependency
bindings and managed microphone test corrections. These fixes remain available
while the qualification above is unfinished.
