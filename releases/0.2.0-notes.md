# Plebian-OS 0.2.0

Candidate record prepared 2026-08-18. This tracked file records source and
upgrade intent; the checksummed provenance asset produced during qualification
will be authoritative for final artifact hashes and operator results. There is
no `v0.2.0` tag or accepted image yet.

Supported upgrade source: **0.1.9**, the immediately previous coordinated
release. No direct skip from an earlier release is supported. Qualification
starts from the published 0.1.9 ISO with SHA-256
`41c46dfe68d4d6a722744c02d30d189c8ed8a0666ec5c8a10aa7116c3b324005`.
Its post-build acceptance record has SHA-256
`64451d7ca17bd2f8d58a7ef122bab9bd30c1734f5e7194702ba589d98dfd393a`,
matching the published `SHA256SUMS`.

## User-visible changes

- Sixteen native libraries now share one staged install/uninstall contract.
  `make install` honors `DESTDIR` and `PREFIX`, publishes a manifest last, does
  not edit loader state, and refuses obstructing directories or symlinks before
  writing anything. `make uninstall` removes only manifest-owned paths and
  fails closed while retaining its manifest if an administrator-modified file
  cannot be removed. Superseded files are retired only while byte-identical to
  their previous manifest entry.
- The supported fleet Python floor is 3.11. Native SONAME generations remain
  independent of the coordinated release number, and installed consumers use
  package-local or `$ORIGIN` discovery; sibling checkout discovery is an
  explicit development override.
- Interactive shells gain a guarded `tb` alias. Existing commands, aliases,
  functions, unreadable files and user-managed alias files are left untouched.
- Kilix gains the coordinated screenshot/start-menu work, full public catalog
  wiring, and the completed TUI surfaces. Eligible local `kilix run`
  applications can negotiate linear DMA-BUF frames through a private rootless
  Weston/PipeWire host and copy GPU-to-GPU into Kitty textures. This is not
  zero-copy scanout; measured hardware work was compositor-limited to roughly
  29–30.5 FPS. Broadcast, headless and encoder paths retain authenticated X11
  capture and `KILIX_RUN_BACKEND=auto|wayland|x11` controls selection.
- Release downloads now carry connection, total-time and byte ceilings with
  oversized partial cleanup. Final per-artifact byte values are part of the
  immutable 0.2.0 manifest rather than mutable network metadata.
- `kilix-bonsai` reports 0.2.0 from both runtimes. Its installers now support
  ownership-safe uninstall of five generated commands: byte-identical
  launchers are removed, edited launchers are deliberately retained. Launchers
  tolerate quote characters in checkout paths, malformed gallery sidecars use
  explicit safe defaults, and unknown variants produce concise diagnostics.
- Kilix NVR commit `f61337589bb130e796ead18fd9fca4a8850fae25` restores the
  complete four-command installed tool set, including `kilix-look-detect`, and
  hardens `--cap-mb` retention parsing. Invalid, negative and overflowing
  limits are refused rather than wrapping into an unsafe byte budget.
- Waydroid ships through public app commit
  `4a331173caf36b3235679715e153e4154b85651f`. First use invokes a fixed,
  root-owned Plebian-OS helper through Kilix SDK; read-only doctor/status paths
  never install. The runtime is the VANILLA LineageOS 20 x86_64 image without
  Google applications or Play services.

## Compatibility and migration

The upgrade moves the complete release-controlled source and dependency closure
as one transaction. It preserves user files, `~/.local/gpu_terminal` data and
game saves, desktop/provider state, shared settings, custom wallpaper/layout,
and operator choices in `/etc/pleb/session.env` that are not release-controlled
pins. XDG application state is unified under the managed data roots with the
old representation retained for rollback; an induced failure must restore the
prior representation and every prior release-controlled key byte for byte.

The final manifest and qualification record will enumerate the exact keys moved
from 0.1.9. Additive apt packages, downloaded cache objects and a newer Go
toolchain may remain after rollback; they do not select or activate the target
closure by themselves.

## Support limits

- Debian 13/Trixie and Python 3.11 or newer are supported.
- Waydroid requires a Binder-capable kernel with real
  `/dev/{binder,vndbinder,hwbinder}` nodes. Q7 runs on the cyberghost VM using
  the final strict image; a VM or host without that real Binder/runtime path is
  not substitute evidence.
- Standalone unmanaged installation has no cross-path rollback. Disabling or
  uninstalling does not remove retained PAM autologin group membership.
- Waydroid accepts one owning session at a time. Closing it must stop only that
  session; cancellation or failure must leave a clean retry.

## Known deferrals

- Standalone cross-path rollback, the managed-host `/tmp` ownership test
  limitation, retained PAM membership, and Plebian-OS generative
  coverage/sanitizer/fuzz mechanisms remain accepted with their recorded risk.
- Approximately thirty inherited native-packaging follow-ups and the game
  consumer-pin/review-fix fan-out remain held while those repositories are
  under concurrent implementation. The provider libraries publish first; game
  consumers move only after their active work settles.
- Known base issues remain dispositioned: the game SDK version-grep failure,
  the Kilix cap-provider mtime flake, and kitty-frame-presenter's two
  blank-line-at-EOF CI complaints.
- `kilix-bonsai` has no declared coverage threshold, type checker, sanitizer,
  property or fuzz gate. Multi-gigabyte model transfers, runtime builds,
  inference, audio capture and playback require separate hardware acceptance
  and are not implied by its passing unit suites.

## Selecting the 0.2.0 closure

Run the selector extracted from the target tag as the Pleb user. The dry run
must validate every exact ref and dependency before the final command changes
release-controlled state:

```sh
SRC="$HOME/.local/gpu_terminal/sources/plebian-os"
SEL="$(mktemp)"
git -C "$SRC" fetch --force origin 'refs/tags/v0.2.0:refs/tags/v0.2.0'
git -C "$SRC" show v0.2.0:provision/plebian-os-select-closure.sh >"$SEL"
bash "$SEL" 0.2.0 --source "$SRC" --dry-run
bash "$SEL" 0.2.0 --source "$SRC"
plebian-os-update --restart
```
