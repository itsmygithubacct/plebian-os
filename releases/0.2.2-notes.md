# Plebian-OS 0.2.2

Source-preparation record begun 2026-09-01. This tracked document records
release intent and operator-visible changes while the exact coordinated closure
is assembled. It is not an acceptance claim: `releases/0.2.2.env`, the
annotated `v0.2.2` candidate tag, and the BIOS/UEFI results must exist before
this record can be finalized.

The attached provenance record is the final artifact
acceptance record for ISO hashes and operator results.
An earlier local candidate ISO, development boot, or passing source test is
useful diagnostic evidence but is not a publishable artifact.

Supported upgrade source: **0.2.1**, the immediately previous coordinated
release and the fresh-install baseline for systems on anything older. No direct
skip from an earlier release is supported. Upgrade acceptance remains separate
from the C5 fresh-install image gate.

## User-visible changes

- **Start and status widgets open above the panes.** The three-line Kilix
  Start button opens an anchored drop-down, and calendar, clock, volume,
  network, battery and temperature cards use the same popup layer. Panes keep
  their size and continue updating. Popups fit the window when resized, open
  upward from a bottom page strip, and dismiss on Escape, an outside click or
  a focus change. The dismissing click cannot activate the pane underneath.
- A whole-stack update now **refuses to start** when sudo needs a password and
  there is no terminal to answer on, instead of failing part-way through. A
  0.2.1 upgrade on real hardware failed exactly that way and left the machine
  with the closure selected but not installed. Set
  `PLEBIAN_OS_ALLOW_UNATTENDED_SUDO=1` to accept that risk deliberately.
- When an update does fail and retains recovery data, it now records **why** in
  `failure-reason` alongside the retained state, and names the commands that
  restore coherence. Previously the reason existed only on the terminal that ran
  it, and was lost if that terminal was reused.
- An incomplete rollback now tells the operator to run
  `plebian-os-select-closure --rollback`, rather than printing retained paths
  and stopping.
- **Copied text now survives closing the app that copied it.** X keeps no
  clipboard store: a selection belongs to a live client and ceases to exist
  when that client exits, and the desktop shipped no clipboard manager, so
  copying in a browser and closing it lost the content every time. The session
  now holds CLIPBOARD and PRIMARY through `autocutsel`. That also keeps the two
  selections in step, so a mouse selection becomes the paste buffer as it does
  on other desktops; `PLEB_CLIPBOARD=clipboard` holds only CLIPBOARD and
  `PLEB_CLIPBOARD=off` restores the previous behaviour; set either in
  `/etc/pleb/session.env` or the user's session.env to keep it across logins.
  A holder already running on the same display is reused; a holder on a
  different display does not prevent this session from starting its own.
- A test that reported the Kilix Cap installer had **destroyed a local
  development checkout** was failing about half of all runs on 0.2.1 and saying
  so falsely; the checkout was never touched. Fixed, so the next time that
  message appears it means something.
- **A pane may now send text to another pane in the same window.** Kilix's
  remote-control policy previously refused `send-text` on the unauthenticated
  path outright. It is permitted within one OS window: a pane may type into
  itself or into a sibling it shares a window with, and may not reach a pane in
  another window. A broadcast, a windowless request, or a match naming no window
  is still refused, and a match resolving to a mixture is refused whole rather
  than for the local part. Kilix's own tooling is unaffected either way — it
  reaches `send-text` with the launcher's private runtime credential.
- **Keys in a contained app pane no longer turn into Alt chords.** `kilix run`
  — which is also how the desktop's Web Browser menu opens a browser — hosts
  an app in a private display and forwarded every key press and release
  into it, bare modifiers included. Leaving the pane with an `alt+arrow` —
  a Kilix binding that moves focus — sent the Alt press in and its release
  elsewhere, so Alt stayed latched in that display and every later key
  reached the app as an Alt chord until something released it. Modifiers now
  travel with the key that needs them and are released with it, and the pane
  lets everything go on focus-out and on exit. Ctrl, Shift and Alt mouse
  clicks and drags preserve their own modifier ownership through the gesture.
- **A contained browser can keep its session.** Every `kilix run chromium` (or
  firefox) launch received a disposable profile, deleted on exit, so each
  launch was a fresh login — and that includes the desktop's own **Web
  Browser** menu, which opens the browser in a `kilix run` tab. `KILIX_RUN_BROWSER_PROFILE=<directory>` in
  `kilix.env` — also offered in Settings — gives every launch one persistent
  profile instead; an explicit `--user-data-dir` or `--profile` still wins.
  One profile means one browser: a second launch joins the first (Chromium)
  or refuses (Firefox). Shared writable and symlink ancestors are refused.
  An owned profile under safe parents is made private without changing any
  existing parent directory or symlink target.
- **The desktop declares its portal backends.** `pleb-session` exports
  `XDG_CURRENT_DESKTOP=Pleb`, but nothing shipped the matching
  `pleb-portals.conf`, so `xdg-desktop-portal` chose every backend by what it
  logs as a "last-resort fallback" and the Settings interface timed out on the
  way. `/etc/xdg-desktop-portal/pleb-portals.conf` now names gtk for every
  interface it implements. ScreenCast and Screenshot are intentionally not
  provided: this image's audio server is PulseAudio, no PipeWire daemon runs,
  and the portal's "Failed connect to PipeWire" line at session start is that
  decision showing, not a fault.
- **`kilix voice doctor` says when there is no audio device.** A machine with
  none still gets a PulseAudio server, serving a null sink, and `kilix speak`
  exits 0 into it. Doctor printed that sink's name and still reported speak
  and dictate healthy. Doctor now checks the selected output and input
  independently: it identifies inaudible null output, missing input and
  monitor capture. A real microphone remains usable when output is null.
- **Throwaway browser profiles are reaped as soon as their owner is gone.**
  Each contained browser launch gets a private profile; a run that ended
  without its own cleanup left ~120 MB behind, and the reaper waited a week
  even when the owning process was dead. Ten of them made 1.2 GB on one 0.2.1
  machine. A dead owner is reaped immediately now. Profiles belonging to a
  live process remain intact, including older profiles without a recorded
  process start time; an unreadable start time never authorizes deletion.
- **Kilix 95 Settings now offers the tab-bar edge.** `KILIX_CHROME_TAB_BAR_EDGE`
  is a shared setting Kilix has had since before 0.2.1, and Kilix 95 never
  surfaced it, so the only way to change it was to edit the settings file. It
  appears in Appearance beside "Tab bar style", taking its choices from the SDK
  rather than restating them. **This gap shipped in 0.2.1**: the stale CI pin
  meant Kilix-95 was tested against a Kilix predating the setting, so the
  assertion that should have caught it could not fire.

## Build and release-process changes

- The artifact's build-info now records `PLEBIAN_OS_NETINST_MAX_BYTES`. Without
  it, `build/acceptance-release-iso.sh` fails on its first manifest check, which
  has been true of every release ISO since 0.2.0.
- `build/remaster-iso.sh` refuses media whose closure **submodule gitlinks** do
  not resolve, not merely whose refs do. A release can have every ref resolve
  and still be un-upgradeable; 0.2.1 proved that.

## Selecting this closure

Run as the Pleb user on the installed machine — never through `sudo`:

```sh
SRC="$HOME/.local/gpu_terminal/sources/plebian-os"
SEL="$(mktemp)"
git -C "$SRC" fetch --force origin 'refs/tags/v0.2.2:refs/tags/v0.2.2'
git -C "$SRC" show v0.2.2:provision/plebian-os-select-closure.sh >"$SEL"
bash "$SEL" 0.2.2
```

Then, and only then:

```sh
plebian-os-update --restart
```

Always execute the selector extracted from the **target** tag. The installed
copy predates this release's validation rules.

## Support limits

- The base image remains Debian 13/Trixie, amd64 only, with no third-party apt
  repositories.
- No model weights ship in the base ISO.
- No SSH server ships in the closure. A freshly installed machine has nothing
  listening on port 22.
