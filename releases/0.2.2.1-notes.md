# Plebian-OS 0.2.2.1 candidate

This maintenance candidate follows 0.2.2. It has not passed final ISO and
upgrade acceptance and is not a published release. The coordinated manifest
will be finalized after source and model-delivery qualification. Existing
0.2.2 tags and artifacts remain unchanged.

## Changes

- Android is optional. Opening its catalog entry installs the pinned Waydroid
  app in user storage, then asks before installing Android and its system
  dependencies. Fresh installs and upgrades stage only the root-owned setup
  helper and its verified configuration. Existing Android installations are
  preserved; an absent optional system archive is no longer hashed as though
  it were installed.
- New lid-policy configuration directories remain readable under a restrictive
  caller umask, so later updates can snapshot them for rollback.
- Model Setup filters submitted passwords before displaying or saving PTY
  output, including echoes split across reads and terminal-mode races.
- The wizard checks conversion prerequisites without requesting administrator
  credentials. OS installation and upgrades install the conversion software
  and the pinned kilix-needle application.
- Standard licences use local distribution-policy authorization. Receipts
  preserve their existing format and record policy provenance separately from
  terminal state. Custom terms still require agreement. Installed licence
  documents are available from the model details window.
- Release selectors, update ordering and media tools accept a positive fourth
  maintenance component, including 0.2.2.1. A fourth component of zero, leading
  zeroes in that component, prerelease suffixes and fifth components are refused.

## Default model bundle

New media must supply the verified archive through
`PLEBIAN_OS_DEFAULT_MODELS_BUNDLE`. The remaster checks its exact size and hash
and includes it in the ISO. Provisioning installs its weights offline. Upgrades
use the same archive, skipping acquisition when all default assets are already
verified. Installation preserves saved model selections.

The nine default assets are:

- YOLOX Nano and YOLOX Small
- YAMNet and Whistle
- Vosk Small English 0.15
- Kilix Female 02
- Needle 3 Kilix Commands
- Needle 2 and its runtime

The archive is 255,638,496 bytes. Its checksum, size and intended release URL
are pinned in `provision/default-models.json`. That URL is a publication target;
it is not evidence that the candidate artifact has been published.

Build it from the selected Kilix source with
`python3 config/default_models.py build --bundle DESTINATION`. The destination
must not exist. Create the reproducible archive from that directory with:

```sh
tar --sort=name --mtime=@0 --owner=0 --group=0 --numeric-owner \
    -cJf default-models-0221.tar.xz -C DESTINATION .
```

Only model files, original notices and the asset manifest enter the bundle.
Build-time receipts remain temporary. The target installation generates its
own local policy receipts. Each installed model retains documents under
`$KILIX_DATA_HOME/desktop-apps/assets/ASSET/notices/`.

Whisper Tiny is excluded: the shipped Whisper installer uses faster-whisper,
whereas the available Tiny artifact is GGML. The separate transcription
adapter requires an engine that this closure does not supply. LFM2 remains an
optional, separately reviewed model under its custom licence.

## Upgrading from 0.2.2

The original 0.2.2 updater rejects four-part versions. Once the immutable
`v0.2.2.1` tag is published, use its closure selector to bootstrap compatibility
before running the updated updater. From the installed desktop account:

```sh
SRC="$GPU_TERMINAL_SOURCE_HOME/plebian-os"
git -C "$SRC" fetch origin refs/tags/v0.2.2.1:refs/tags/v0.2.2.1
SEL="$(mktemp)"
git -C "$SRC" show v0.2.2.1:provision/plebian-os-select-closure.sh >"$SEL"
bash "$SEL" 0.2.2.1 --source "$SRC" --dry-run
bash "$SEL" 0.2.2.1 --source "$SRC"
rm -f "$SEL"
plebian-os-update --revalidate-current
```

These commands depend on the final published tag and manifest. They are not
instructions to install the current unqualified source candidate.

## Acceptance still required

The fresh-install baseline must be rebuilt with the new default bundle and
tested in BIOS and EFI modes, followed by an upgrade from the released 0.2.2
closure. The model-compliance delivery statement must reflect bundled Vosk and
Whistle instead of reusing 0.2.2's first-use-only statement. Qualification must
also cover the installed converters, Needle, preserved choices and rollback.

No earlier local candidate ISO establishes this candidate's acceptance. After
those checks, the attached provenance record is the final artifact
acceptance record; no such final record exists yet for this candidate.
