# Plebian-OS 0.2.1

Source-preparation record begun 2026-08-25. This tracked document records
release intent and operator-visible changes while the exact coordinated closure
is assembled. It is not an acceptance claim: `releases/0.2.1.env`, the
annotated `v0.2.1` candidate tag, and the BIOS/UEFI results must exist before
this record can be finalized.

The attached provenance record is the final artifact
acceptance record for ISO hashes and operator results. An earlier local candidate
ISO, development boot, or passing source test is useful diagnostic evidence but
is not a publishable artifact.

Supported upgrade source: **0.2.0**, the immediately previous coordinated
release and the fresh-install baseline for systems on anything older. No direct
skip from an earlier release is supported. Upgrade acceptance remains separate
from the C5 fresh-install image gate.

## User-visible changes

- Normal installation media no longer ships a shared account or password.
  Debian Installer asks for hostname, full name, account name, and a concealed
  twice-entered password. Automated VM acceptance uses a separately labelled,
  temporary credential path.
- Provisioning discovers and validates the installer-created account rather
  than assuming a fixed username or home directory.
- Pleb updates refuse development worktrees and preserve untracked files,
  submodule state, and rollback metadata instead of advising destructive
  cleanup.
- Kilix includes lazy Techno soundbanks backed by the reviewed CC0 sound packs.
- Operator advice launches mpv with the terminal renderer chain
  `vo=kitty,sixel,tct`, so following the shipped command does not open a GUI
  window.
- The coordinated closure carries repository-root pins for the system-monitor,
  desktop-SDK, IceWM, media-SDK, and Waydroid release graphs. Their component
  metadata and gitlinks are verified from the selected commits rather than
  duplicated as independently editable env values.
- The release requires the checksum-verified uv 0.12.5 installer and binds its
  71,225-byte input limit as part of the installed closure. It also retains the
  hash-bound Waydroid first-use helper without adding Android or Weston to the
  base package set.
- Chromium remains the universal default browser while Firefox ESR stays out
  of the base image until selected by setup. The fresh image now explicitly
  installs `xfce4-screenshooter`, which backs the desktop's Print shortcuts.

## Compatibility and migration

The 0.2.1 selector moves every release-controlled value as one transaction and
preserves operator-controlled session and storage settings. The five new root
tuples each require a canonical HTTPS repository, a full lowercase commit, and
an explicitly empty branch. A missing tuple member, a mutable ref, a
requirements mismatch, or a placeholder is refused before session state is
written.

Standalone Kilix 95 remains the legacy/rollback identity. The final desktop SDK
selection comes from the desktop-SDK root; release graph verification must
refuse two active Kilix 95 instances unless the owner records an explicit
legacy-only or process-isolation disposition.

The final `releases/0.2.1.env` must repeat those values exactly and will name
every public source commit, Debian snapshot, verified installer input, engine
archive, and optional runtime closure used by the image. This document
deliberately does not substitute provisional commit IDs for that manifest.

## Support limits

- The base image remains Debian 13/Trixie, amd64 only, with no third-party apt
  repositories.
- No model weights ship in the base ISO. An empty optional-component catalog is
  a supported state.
- Hardware/model qualification claims are limited to the exact devices and
  artifacts recorded by the final acceptance evidence.
