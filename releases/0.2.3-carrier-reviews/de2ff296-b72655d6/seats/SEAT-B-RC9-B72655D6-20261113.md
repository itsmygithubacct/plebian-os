## Compiler selection

`build.sh` reads the first `toolchain go…` line from `src/go.mod`. An exact caller value `GOTOOLCHAIN=local` replaces that line. `KILIX_GO_TOOLCHAIN` then overrides either result, including `local`. An empty selection falls back to `go1.26.4`. The exported value must be `local` or `goX.Y[.Z]`. `go1.27.3+auto` exits 2 before the build. `GOTOOLCHAIN=auto`, and a caller `GOTOOLCHAIN` set to a version other than the word `local`, are replaced by the go.mod line or the fallback unless `KILIX_GO_TOOLCHAIN` carries the version. The README states the same order. `bash -n build.sh` passed.

The release provisioner is unchanged from `ecb5d279`. With `PLEBIAN_OS_KILIX_GO_DEBIAN_VERSION` set, `ensure_go_for_kilix_build` puts `/usr/lib/go-1.27/bin` first on `PATH` and exports `GOROOT=/usr/lib/go-1.27`, `GOENV=off`, and `GOTOOLCHAIN=local`. It does not set `KILIX_GO_TOOLCHAIN`. `build_kilix_fork` runs `kilix --build`, and the launcher executes `build.sh`, so that environment reaches the selection. The updater records `go version` through `GOTOOLCHAIN=local /usr/lib/go-1.27/bin/go version` and does not invoke the engine build. `RELEASING.md` tells the operator to verify that `GOTOOLCHAIN=local` and the selected compiler reach the engine build.
