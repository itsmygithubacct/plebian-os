## Compiler selection

`build.sh` reads the `toolchain` line from `src/go.mod`. The exact caller value `GOTOOLCHAIN=local` replaces that line. Any other caller value, including `auto` and `go1.27.3`, leaves the module line in place. `KILIX_GO_TOOLCHAIN`, when set, replaces both. The result must be `local` or an exact `go` version, or the script exits 2 before a build directory is created. The script exports that value once. The launcher `--build` execs `build.sh`, so the exported value is the one the engine build receives.

Those selection statements, run against a temporary module whose `go.mod` contains the engine lines `go 1.26.0` and `toolchain go1.27.0`, produce:

- unset caller: `go1.27.0`
- `GOTOOLCHAIN=local`: `local`
- `GOTOOLCHAIN=auto`: `go1.27.0`
- `GOTOOLCHAIN=go1.27.3`: `go1.27.0`
- `GOTOOLCHAIN=local` with `KILIX_GO_TOOLCHAIN=go1.27.3`: `go1.27.3`
- `GOTOOLCHAIN=local` with `KILIX_GO_TOOLCHAIN=go1.27.3+auto`: exit 2 and `invalid exact KILIX_GO_TOOLCHAIN`

The prior statements at Kilix `eb29f69e8e51b069a805557575b8147a43e54488` export `go1.27.0` for an unset caller, for `local`, for `auto`, and for `go1.27.3`.
