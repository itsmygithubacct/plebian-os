# Plebian-OS 0.2.3 RC5 candidate

This candidate follows the local `v0.2.3-rc4` tag. It keeps the patched 0.2.2.1
sources and the selected 0.2.3 integration. Image, update, and final release
acceptance are open. The numeric release is `v0.2.3`. `PLEBIAN_OS_REF` names the annotated
local upgrade candidate `v0.2.3-rc5`; this tag does not establish whole-release
acceptance.

## Defaults

The RC5 candidate includes these Kilix defaults.

- Ask uses `lfm2-kilix-v5e1-wse-20261106.9`. The installer bundles delivery
  archive `lfm2-kilix-commands-20261106-v9`. Rollback is
  `lfm2-kilix-commands-20261104-v8`. The archive is published as kilix-needle
  release `lfm2-kilix-commands-20261106-v9`.
- Help uses `kilix-qwen-sft1-2b`. `kilix help-setup` downloads the published
  adapter release, then `kilix help-answer` asks it. `kilix help-search` does
  not need the weights. The Help selection record pins help-llm source
  `4abc52e9236899a05738807d32a3431270b6a3c2`.

## Changes

- Install without a network mirror. With no network package source, the
  installer no longer stops at "Select and install software"; first-boot
  provisioning installs those packages from the network, as it does after a
  network install. Wired interfaces get DHCP from the base system's dhcpcd as
  soon as a cable is connected, until provisioning has installed
  NetworkManager and hands them to it. Every install now disables the
  install medium's apt entry, which provisioning refused. Resume an exhausted
  first boot as before: remove `/var/lib/plebian-os/firstboot-attempts` and
  start `plebian-os-firstboot.service`. A machine with only wireless
  networking still cannot join a network before provisioning.
- Install `python3-torch=2.6.0+dfsg-7` and the pinned model-converter
  dependencies automatically during upgrades, matching fresh provisioning.
  The converter helpers run only after those dependencies are installed.
- Accept `kilix ask --yes REQUEST` for an explicitly confirmed request.
  A refusal or an unsure route still does not run; `--yes` and `--voice`
  cannot be combined.

- Open the installed GParted program through sudo. Kilix asks for the
  administrator password in a dialog on the session display. The private
  desktop bus does not grant that root launch.
- Select `lfm2-kilix-v5e1-wse-20261104.8` as the default Kilix Ask command model.
  Bundle its separately verified 1.36 GB archive on the ISO and stage it during
  upgrades with admin rights. Preserve explicit choices and earlier models for
  rollback. The small nine-model bundle remains unchanged.
- Preserve literal message copying and complete immediate launch requests while
  retaining the current command-boundary, startup and transport checks.
- Offer Whisper medium English (`whisper-medium-en`, Systran
  faster-whisper-medium.en at `a29b04bd`, 1.4 GiB) as a second Whisper
  dictation model next to `whisper-small-en`. It is a first-use download with
  its own licence record, `faster-whisper-medium-en` (owner determination
  2026-11-07), whose terms are those of small: MIT, licensors OpenAI and
  SYSTRAN. It is not in the image; from RC5 an online upgrade also installs it
  as a Playalong default (below).
- Add `kilix transcribe`, which lists the speech engines, installs one through
  the model catalog, and transcribes a recording in chunks; `--clean`
  transcribes the separated vocals. Add `kilix split`, which separates a mix
  into stems with a private Demucs install (`kilix split --install`). Its
  separation weights (`demucs-htdemucs-6s`: Meta's htdemucs_6s, MIT, owner
  determination 2026-11-08) are a first-use model with their own licence
  record, installed through `kilix models install` after the licence screen;
  split refuses without a covering receipt and runs Demucs offline against the
  verified files.
- Install Kilix Playalong's default models when they are missing, by the
  owner's 2026-11-08 decision: Demucs htdemucs_6s, Basic Pitch and Whisper
  medium.en, all under the standard distribution policy. Demucs now ships in
  the image as `demucs-htdemucs-6s.tar`, Meta's unchanged weights file with the
  Demucs MIT text beside it. The build writes that archive from Meta's pinned
  URL and checks it against `provision/demucs-model.json`. A fresh install
  takes Demucs and Basic Pitch from the image and downloads nothing. An online
  upgrade downloads what the machine lacks: Demucs from Meta's URL when the
  image did not supply it, and Whisper medium.en from its pinned revision.
  Each download is checked against the pinned digests. A failed download
  installs nothing, and the next upgrade tries again: the receipt it leaves
  without files reads as "not installed", not as a failed upgrade. A machine
  declines all three when the model wizard's Playalong page was answered no,
  when the licence of one of the three was refused in the model wizard, or when
  `KILIX_PLAYALONG_MODELS=0` is set in the shared settings file. Refusing only
  Whisper large-v3's licence declines nothing. If that answer cannot be read,
  none of the three is installed. Whisper large-v3 (`faster-whisper-large-v3`,
  MIT, owner determination 2026-11-08) is offered on the Playalong page for
  lyrics that are not in English. It is installed only after a yes. The
  carrier gives medium.en its own delivery mode,
  `playalong-default-upstream-download`, bound to
  `provision/playalong-models.json`.

- Preserve password transcript filtering, offline defaults, standard licence
  policy and model notices from the patched baseline.
- Clear the previous Waydroid closure hash when automatic installation is
  disabled, including on machines with split release configuration.
- Make Android optional. The catalog installs the application on demand;
  installation and updates stage the first-use setup helper. Android itself
  requires first-use confirmation.
- Preserve the updater fixes for missing optional app provenance and readable
  lid-policy directories under restrictive permissions.
- Include the selected terminal, desktop launch, transport, camera and model
  integration source changes from 0.2.3.
- Bind the model-delivery record to the exact nine-model bundle. Vosk Small
  and Whistle are bundled; other advertised speech models remain deferred.
- Select `kilix-qwen-sft1-2b` as the default Help answer model. Run
  `kilix help-setup` once, then `kilix help-answer "How do I list panes?"`
  for a command, a short explanation and related documentation links.
  `kilix help-search` remains available without model weights.

The Help adapter is hosted as a versioned
[model release](https://github.com/itsmygithubacct/kilix-help-llm/releases/tag/kilix-qwen-sft1-2b).
Setup verifies the adapter and the exact upstream Qwen3.5-2B parent, and uses
the shared resource check before local CPU inference. This is an explicit
first-use download, separate from the existing nine-model archive.
[The Help selection record](0.2.3-help-model.json) binds the model hashes,
parent revision, and help-llm source pin carried from the RC4 candidate.
The [Help setup and troubleshooting guide](https://github.com/itsmygithubacct/kilix/blob/6b6dbda8d75fe787b6e3bdfaac597980251fd03c/docs/help/answers.md) covers everyday questions, installation checks and documentation search.

The selected model scored 30/32 on exposed everyday help questions and 8/8 on
unknown-state refusals. It scored 41/72 on the older retention set, versus
49/72 for its parent. These fixed-evidence development results do not establish
independent qualification or whole-system answer accuracy.

The [command-model selection](0.2.3-command-model.json) binds the LFM2 release,
source revisions and rollback to `20261104.8`. On GPU, `20261106.9` is ahead of
`20261106.8`: development raw 1378/1383 against 1372/1383, admitted 1346/1383
with no change, probes 61/64 against 60/64, fresh confirmation 146/160 against
145/160, operational 28/32 with no change, and expand 8/8 against 7/8.
Admitted losses versus `20261106.8` are zero on those suites. The admitted
gains are `copy-probe-028`, `copy-fresh-039`, and `literal-expand-004`. CPU
was not run. These results measure Kilix commands, not general reasoning.
They used Needle runtime `4f3aeaff`. The catalog now selects Needle
`a887e2fa`, whose bundled catalog and licence records carry this delivery and
the LFM2 notice record. With no receipt, it says that no receipt records that
the LFM2 terms were shown, not that the licence "has not been accepted". Its
grammar is unchanged from `3a8e41c5`: it reads an
unquoted spaced path only when that exact path exists, and reads a bare right,
left or down before an explicit path as the placement. The grammar alone reads
1352/1383 development cases with no wrong action, against 1346/1383 at
`073f5e03`, with the same probe, fresh, operational and expand results.
Admitted results with the model were not rerun.

The model and runtime licence documents are staged at
`/usr/local/share/doc/plebian-os/models/lfm2-kilix-commands-20261106-v9/notices/`.
By the owner's 2026-11-07 determination, LFM2's terms, including the
commercial-use limitation, are a notice, as with a Debian non-free package.
Installation and upgrades install the staged archive and record a notice
receipt for the exact current licence and manifest. The receipt claims no
agreement, and the terms are not waived. Terms that need a typed agreement are
never answered by the image.

## Qualification

The intended fresh-install baseline and supported upgrade source are 0.2.2.
Fresh BIOS/EFI installations, update/rollback, converter/Needle end-to-end
checks and final artifact acceptance are pending. Earlier source reviews and
an earlier local candidate ISO do not qualify this combined release.

The attached provenance record is the final artifact
acceptance record only after the artifact has passed those checks; none is
claimed by these candidate notes. Diarization quality, hardware qualification
and deferred model campaigns retain their recorded limitations. The
kilix-diarization-cpu notice licensors match the licence-record string a
receipt binds.
Installing model files does not establish provider activation or inference
quality.

The default bundle retains its original filename `default-models-0221.tar.xz`
and checksum. Its intended RC1 asset URL is not published yet.
