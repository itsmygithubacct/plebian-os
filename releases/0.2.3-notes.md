# Plebian-OS 0.2.3 RC8 candidate

This candidate follows the published `v0.2.3-rc7` tag (commit `b7e7e0d3`).
It keeps that closure and adds the follow-ups below. Paradee and
`en_core_web_sm` are in the image. The numeric release is
`v0.2.3`. `PLEBIAN_OS_REF` names the annotated candidate `v0.2.3-rc8`.
The local tag does not name this commit. Image boot acceptance is not claimed.

## Defaults

This candidate keeps these Kilix defaults.

- Ask uses `lfm2-kilix-v5e1-wse-20261106.9`. The installer bundles delivery
  archive `lfm2-kilix-commands-20261106-v9`. Rollback is
  `lfm2-kilix-commands-20261104-v8`. The archive is published as kilix-needle
  release `lfm2-kilix-commands-20261106-v9`.
- Help uses `kilix-qwen-sft1-2b`. `kilix help-setup` downloads the published
  adapter release, then `kilix help-answer` asks it. `kilix help-search` does
  not need the weights. The Help selection record pins help-llm source
  `4abc52e9236899a05738807d32a3431270b6a3c2`.

## Changes

- Follow published RC7 with these component fixes. kilix-llm
  `93f2202be062cb443daf9a3d47243098d9567bf6` refuses
  `kilix-llm pull --model-id qwen-0.8b-no-loop-02` and names
  `kilix models install qwen-0.8b-no-loop-02`. Its runtime build passes
  `-DLLAMA_USE_PREBUILT_UI=OFF`, so a first-use build does not fetch
  llama.cpp's web UI. Kilix Avatar
  `202f03cd2834c7979f9399d6e03caa823786d2dd` names that same install
  command when the model file is missing. Kilix is
  `b77e49b37068a8fad7be110cad830c17407edbaa` and Kilix 95 is
  `fdf62f1e798820f70a5646df379e2df0b9ab8e71`. Ask answers a closed
  sum, the time, disk, memory, CPU, one sensor reading, volume,
  brightness, the network name, the current track, and an alarm
  directly. An integer sum prints in full, a conversion keeps its
  unit, and "and" is addition except inside one hundred. A written
  thousand, million, or billion still reads as that number.
  `kilix ask --repl` stays open until exit, quit, or the end of
  input, including a final line with no newline. How-to search calls
  the installed help program. A wifi question uses wifi devices only.
  A temperature down to -100°C is a reading. Ask also answers dates
  and other clocks, facts about this computer, unit conversions, text
  and status-code questions, and dice directly, and "what can you
  do?" lists them. Courtesy around a request is ignored. The numeric
  keypad is
  injected into a private X app, so Chromium under `kilix run`
  receives digits, operators, and keypad arrows. Kilix's
  kilix-telemetry gitlink is
  `ea35206cc0a2cfde422d1112a99d6245f55d57c6`. kilix-content
  `32722d0be0e00974635ba3ab2ee9543fa35db92f` catalogues PDF Conversion's
  page OCR models. Its parent `c7aaac12` selects Needle `30ee74fe`. The
  image carrier
  `09ef84aef8826e45fb133fb8b3ef1de8f72fa4fb772f89dc8bc9ea79caf4e28e`
  binds that content commit and
  kilix-license `596ada2ab68b9ec441674ff4da2d431559d47378`. Paradee and
  `en_core_web_sm` are `image-offline-model`. On an online upgrade of a
  machine installed without their archives, the updater downloads the
  pinned files and wheels as root. It builds the same archives and checks
  them against the image pins before installing. Two seats reviewed this
  carrier and both say ship with known issues.
- Offer `qwen-0.8b-no-loop-02` on the model wizard's other language models
  page. It is Qwen3.5-0.8B (Q8_0) with one third of a published weight edit
  applied to 64 `ffn_down` columns in layers 15 and 19, so that thinking mode
  loops less often. It is not a default and is not on the installation media:
  the wizard downloads it from the kilix-llm release
  [`qwen-0.8b-no-loop-02`](https://github.com/itsmygithubacct/kilix-llm/releases/tag/qwen-0.8b-no-loop-02)
  (833592416 bytes, sha256 `e4d6e93eb644da62e0c5ac0b7b188b4c2cbf31f07a7dcfd42764b6236f96d8a0`)
  under the standard licence policy. Its licence record has an Apache-2.0 row
  (Alibaba Cloud / Qwen; itsmygithubacct is the modifier) and a CC BY 4.0 row
  for the weight edit, both approved by the owner. The asset installs both
  texts, the modification notice and the attribution.
- Install kilix-llm at the Kilix-pinned commit
  `93f2202be062cb443daf9a3d47243098d9567bf6` during installation and upgrades:
  the launcher and a shallow copy of its pinned llama.cpp source, with nothing
  compiled. With the model installed, Kilix 95 offers
  **LLM Chat (Qwen 0.8B no-loop)** (`kilix-llm chat`, thinking on) and
  **Kilix Avatar (Qwen 0.8B no-loop)** (thinking off). Both run on CPU. The
  first start of either builds kilix-llm's CPU runtime once and does not fetch
  llama.cpp's web UI. `kilix-llm pull` of this model id is refused. On the
  published RC7 pin, that build took 6 min 56 s on a 2 vCPU guest upgraded
  from RC6 (on a busy host) and added 23 MB. A later start found it built in
  0.2 s. A machine that never uses the model does not pay for a provisioning
  build.
- On fresh seeds with thinking on at temperature 0.7 / top_p 0.8, the model
  looped in 10 of 80 replies against 23 for the original (paired 3 against 16,
  p = 0.004). At the Qwen card sampler (1.0 / 0.95) there was no difference.
  Over 1064 paired GSM8K problems the original alone was right 114 times and
  this model alone 115 times. With thinking off and no presence penalty it ran
  past 1024 tokens more often (56 against 40 of 400, p = 0.048); with the
  presence penalty kilix-llm serves there was no difference. The model card
  in the release has the full evaluation and its limits.
- Build Kilix's engine with Go 1.27.3 in place of 1.27.0: the go.dev archive,
  sha256-pinned for each architecture as before. Go 1.27.2 and 1.27.3 are
  security releases (the go command, crypto/tls, crypto/x509, html/template,
  net/http, net/textproto and os). A fresh install fetches and verifies it.
  An upgrade from RC6 keeps go1.27.0 and its engine: Pleb checks Go only when
  it rebuilds the engine, and RC7 does not change the engine's source.
  The image also configures Debian's `<codename>-backports` archive in
  `plebian-os-debian-backports.sources` and removes it while apt is pinned
  to a snapshot. Apt's default priority leaves that suite unselected. This
  candidate still installs Go from the go.dev archive above.

- Install without a network mirror. With no network package source, the
  installer no longer stops at "Select and install software"; first-boot
  provisioning installs those packages from the network, as it does after a
  network install. Wired interfaces get DHCP from the base system's dhcpcd as
  soon as a cable is connected, until provisioning has installed
  NetworkManager and hands them to it. Every install now disables the
  install medium's apt entry, which provisioning refused. Resume an exhausted
  first boot as before: remove `/var/lib/plebian-os/firstboot-attempts` and
  start `plebian-os-firstboot.service`. A machine with only wireless
  networking still cannot join a network before provisioning.
- Install Tesseract 5.5.0 with English data (`tesseract-ocr`,
  `tesseract-ocr-eng`) on fresh installs and upgrades. kilix-pdf-conversion
  0.4.0 (`2cff8ffde2a64367ca2e3e567acfcb740866fb9f`) reads scanned pages
  with it or with RapidOCR, chosen per page.
- Ship PDF Conversion's page OCR models in the image. `pp-ocrv6-small-det`
  and `pp-ocrv6-small-rec` are PaddlePaddle's PP-OCRv6 small text detector
  and recogniser as ONNX, unchanged from Hugging Face at revisions
  `28fe5895` and `b8f84f0b`. The owner determined Apache-2.0 for both on
  2026-11-10 and raised the PDF model count from three to five. The model
  cards state Apache-2.0, but neither repository has a LICENSE or NOTICE
  file, and the cards name no copyright holder. Each archive therefore
  carries Debian's Apache-2.0 text, and the licence records say so. The two
  archives are 9,902,080 and 21,329,920 bytes. A fresh install installs both
  offline into the content root. An upgrade on a machine without them
  downloads the same files from the pinned revisions. Every file is checked
  for size and SHA-256 first. Both models install whether or not
  Playalong's models were declined. They are outside the voice carrier,
  like Demucs.
- Install `python3-torch=2.6.0+dfsg-7` and the pinned model-converter
  dependencies automatically during upgrades, matching fresh provisioning.
  The converter helpers run only after those dependencies are installed.
- Accept `kilix ask --yes REQUEST` for an explicitly confirmed request.
  A refusal or an unsure route still does not run; `--yes` and `--voice`
  cannot be combined.

- Open the installed GParted program through sudo. Kilix asks for the
  administrator password in a dialog on the session display. The private
  desktop bus does not grant that root launch.
- Select `lfm2-kilix-v5e1-wse-20261104.8` as the default Kilix Ask command model.
  Bundle its separately verified 1.36 GB archive on the ISO and stage it during
  upgrades with admin rights. Preserve explicit choices and earlier models for
  rollback. The small nine-model bundle remains unchanged.
- Preserve literal message copying and complete immediate launch requests while
  retaining the current command-boundary, startup and transport checks.
- Offer Whisper medium English (`whisper-medium-en`, Systran
  faster-whisper-medium.en at `a29b04bd`, 1.4 GiB) as a second Whisper
  dictation model next to `whisper-small-en`. It is a first-use download with
  its own licence record, `faster-whisper-medium-en` (owner determination
  2026-11-07), whose terms are those of small: MIT, licensors OpenAI and
  SYSTRAN. It is not in the image; from RC6 an online upgrade also installs it
  as a Playalong default (below).
- Add `kilix transcribe`, which lists the speech engines, installs one through
  the model catalog, and transcribes a recording in chunks; `--clean`
  transcribes the separated vocals. Add `kilix split`, which separates a mix
  into stems with a private Demucs install (`kilix split --install`). Its
  separation weights (`demucs-htdemucs-6s`: Meta's htdemucs_6s, MIT, owner
  determination 2026-11-08) are a first-use model with their own licence
  record, installed through `kilix models install` after the licence screen;
  split refuses without a covering receipt and runs Demucs offline against the
  verified files.
- Install Kilix Playalong's default models when they are missing, by the
  owner's 2026-11-08 decision: Demucs htdemucs_6s, Basic Pitch and Whisper
  medium.en, all under the standard distribution policy. Demucs now ships in
  the image as `demucs-htdemucs-6s.tar`, Meta's unchanged weights file with the
  Demucs MIT text beside it. The build writes that archive from Meta's pinned
  URL and checks it against `provision/demucs-model.json`. A fresh install
  takes Demucs and Basic Pitch from the image and downloads nothing. An online
  upgrade downloads what the machine lacks: Demucs from Meta's URL when the
  image did not supply it, and Whisper medium.en from its pinned revision.
  Each download is checked against the pinned digests. A failed download
  installs nothing, and the next upgrade tries again: the receipt it leaves
  without files reads as "not installed", not as a failed upgrade. A machine
  declines all three when the model wizard's Playalong page was answered no,
  when the licence of one of the three was refused in the model wizard, or when
  `KILIX_PLAYALONG_MODELS=0` is set in the shared settings file. Refusing only
  Whisper large-v3's licence declines nothing. If that answer cannot be read,
  none of the three is installed. Whisper large-v3 (`faster-whisper-large-v3`,
  MIT, owner determination 2026-11-08) is offered on the Playalong page for
  lyrics that are not in English. It is installed only after a yes. The
  carrier gives medium.en its own delivery mode,
  `playalong-default-upstream-download`, bound to
  `provision/playalong-models.json`.

## Qualification

The intended fresh-install baseline and supported upgrade source are 0.2.2.
Fresh BIOS/EFI installations, update/rollback, converter/Needle end-to-end
checks and final artifact acceptance are pending. Earlier source reviews and
an earlier local candidate ISO do not qualify this combined release.
The RC7 carrier `42b6956b` was reviewed by two seats, both "ship with known
issues", listed in [the follow-ups](0.2.3-followups.md). This candidate's
carrier is `09ef84aef8826e45fb133fb8b3ef1de8f72fa4fb772f89dc8bc9ea79caf4e28e`.
Paradee and `en_core_web_sm` are `image-offline-model`. Two seats reviewed
this carrier and both say ship with known issues. Kilix 95's
workflow names Kilix `b77e49b3`. Image boot acceptance is not claimed.

The attached provenance record is the final artifact
acceptance record only after the artifact has passed those checks; none is
claimed by these candidate notes. Diarization quality, hardware qualification
and deferred model campaigns retain their recorded limitations. The
kilix-diarization-cpu notice licensors match the licence-record string a
receipt binds.
Installing model files does not establish provider activation or inference
quality.

The default bundle retains its original filename `default-models-0221.tar.xz`
and checksum. Its intended RC1 asset URL is not published yet.

## Known issues

- A first standalone closure selection is refused. On a standalone Debian
  machine that has never selected a Plebian-OS closure, `pleb update --to`
  stops with "could not select the split closure (status 6)": the selector
  reads its rollback record from session.env, which holds no release version
  yet. Machines that selected a closure before, including upgrades from
  0.2.2, keep that record and are not affected. Release owner decision,
  2026-11-09; see [the follow-ups](0.2.3-followups.md).
