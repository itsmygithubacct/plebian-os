# Plebian-OS 0.2.3 RC4 candidate

This candidate follows published `v0.2.3-rc3`. It keeps the patched 0.2.2.1
sources and the selected 0.2.3 integration. Image, update, and final release
acceptance are open. The numeric release is `v0.2.3`. `PLEBIAN_OS_REF` names the annotated
local upgrade candidate `v0.2.3-rc4`; this tag does not establish whole-release
acceptance.

## Defaults

The RC4 candidate includes these Kilix defaults.

- Ask uses `lfm2-kilix-v5e1-wse-20261104.8`. The installer bundles delivery
  archive `lfm2-kilix-commands-20261104-v8`.
- Help uses `kilix-qwen-sft1-2b`. `kilix help-setup` downloads the published
  adapter release, then `kilix help-answer` asks it. `kilix help-search` does
  not need the weights. The Help selection record pins help-llm source
  `4abc52e9236899a05738807d32a3431270b6a3c2`.

## Changes

- Accept `kilix ask --yes REQUEST` for an explicitly confirmed request.
  A refusal or an unsure route still does not run; `--yes` and `--voice`
  cannot be combined.

- Open the installed GParted program through sudo. Kilix asks for the
  administrator password in a dialog on the session display. The private
  desktop bus does not grant that root launch.
- Select `lfm2-kilix-v5e1-wse-20261104.8` as the default Kilix Ask command model.
  Bundle its separately verified 1.36 GB archive on the ISO and stage it during
  upgrades with admin rights. Preserve explicit choices and earlier models for
  rollback. The small nine-model bundle remains unchanged.
- Preserve literal message copying and complete immediate launch requests while
  retaining the current command-boundary, startup and transport checks.

- Preserve password transcript filtering, offline defaults, standard licence
  policy and model notices from the patched baseline.
- Make Android optional. The catalog installs the application on demand;
  installation and updates stage the first-use setup helper. Android itself
  requires first-use confirmation.
- Preserve the updater fixes for missing optional app provenance and readable
  lid-policy directories under restrictive permissions.
- Include the selected terminal, desktop launch, transport, camera and model
  integration source changes from 0.2.3.
- Bind the model-delivery record to the exact nine-model bundle. Vosk Small
  and Whistle are bundled; other advertised speech models remain deferred.
- Select `kilix-qwen-sft1-2b` as the default Help answer model. Run
  `kilix help-setup` once, then `kilix help-answer "How do I list panes?"`
  for a command, a short explanation and related documentation links.
  `kilix help-search` remains available without model weights.

The Help adapter is hosted as a versioned
[model release](https://github.com/itsmygithubacct/kilix-help-llm/releases/tag/kilix-qwen-sft1-2b).
Setup verifies the adapter and the exact upstream Qwen3.5-2B parent, and uses
the shared resource check before local CPU inference. This is an explicit
first-use download, separate from the existing nine-model archive.
[The Help selection record](0.2.3-help-model.json) binds the model hashes,
parent revision, and help-llm source pin in this RC4 candidate.
The [Help setup and troubleshooting guide](https://github.com/itsmygithubacct/kilix/blob/6b6dbda8d75fe787b6e3bdfaac597980251fd03c/docs/help/answers.md) covers everyday questions, installation checks and documentation search.

The selected model scored 30/32 on exposed everyday help questions and 8/8 on
unknown-state refusals. It scored 41/72 on the older retention set, versus
49/72 for its parent. These fixed-evidence development results do not establish
independent qualification or whole-system answer accuracy.

The [command-model selection](0.2.3-command-model.json) binds the LFM2 release,
source revisions and rollback. On the fresh 160-request internal test, `.8`
produces 139 exact responses versus `.21`'s 134 on CPU and GPU, with no observed
regressions. Application validation yields 143 correct results versus 138 and
admits no incorrect action. Three false abstentions remain. The 32-request
operational audit ties `.21`; its disclosed overlap and label correction limit
independence. These results measure Kilix commands, not general reasoning.

The model and runtime licence documents are staged at
`/usr/local/share/doc/plebian-os/models/lfm2-kilix-commands-20261104-v8/notices/`.
Archive staging does not create a custom-licence agreement. The exact current
licence and manifest still require coverage before the model is selected.

## Qualification

The intended fresh-install baseline and supported upgrade source are 0.2.2.
Fresh BIOS/EFI installations, update/rollback, converter/Needle end-to-end
checks and final artifact acceptance are pending. Earlier source reviews and
an earlier local candidate ISO do not qualify this combined release.

The attached provenance record is the final artifact
acceptance record only after the artifact has passed those checks; none is
claimed by these candidate notes. Diarization quality, hardware qualification
and deferred model campaigns retain their recorded limitations. The
kilix-diarization-cpu notice licensors match the licence-record string a
receipt binds.
Installing model files does not establish provider activation or inference
quality.

The default bundle retains its original filename `default-models-0221.tar.xz`
and checksum. Its intended RC1 asset URL is not published yet.
