# Plebian-OS 0.2.3 RC9 candidate

This branch prepares RC9 on top of the frozen RC8 source line. It adds Zell
0.1.1 and the RC9 Kilix changes below. The numeric release remains `v0.2.3`.
`PLEBIAN_OS_REF` reserves `v0.2.3-rc9`; this change creates no candidate tag or
ISO and makes no image boot acceptance claim.

## Defaults

This candidate keeps these Kilix defaults.

- Ask uses `lfm2-kilix-v5e1-wse-20261106.9`. The installer bundles delivery
  archive `lfm2-kilix-commands-20261106-v9`. Rollback is
  `lfm2-kilix-commands-20261104-v8`. The archive is published as kilix-needle
  release `lfm2-kilix-commands-20261106-v9`.
- Help uses `kilix-qwen-sft1-2b`. `kilix help-setup` downloads the published
  adapter release, then `kilix help-answer` asks it. `kilix help-search` does
  not need the weights. The Help selection record pins help-llm source
  `4abc52e9236899a05738807d32a3431270b6a3c2`.

## Changes

- `kilix video --neuronte FILE` launches the installed Neuronte player with
  sound, pause and seek. Its steady clock and child-process cleanup fixes
  are included in the selected runtime. Explicit `--pixel-size` output allows
  equal-resolution comparisons. Contiguous frame buffers and one default
  scaler worker reduce CPU use; `--filter-threads 0` restores automatic
  worker selection. Playback honors the source chroma location and drains
  pending shared-memory frames before exit. Decoder diagnostics cannot block
  playback, controls remain responsive during stalled reads and long frame
  intervals, and rates below one frame per second honor their full deadlines.
  Invalid log paths leave terminal settings intact. Kilix 95 CI tests this host.
- Select kilix-mpv `0.40.0+kilix.9` for Debian 13 amd64. It converts decoded
  YUV to RGB while scaling to the terminal size, removing the previous
  full-resolution conversion. It also corrects chroma offsets on RGB and
  unsubsampled YUV axes. Regression tests compare odd-sized RGB24, YUV420,
  YUV422 and YUV444 output against FFmpeg with explicit chroma locations.
  Queued frames receive a bounded acknowledgment wait during shutdown.
  The package passed CI, graphical controls with both transports, and install, upgrade and
  rollback checks in a disposable Debian container.

- Bundle Zell 0.1.1 at `ccc741f76ab7d0de93dc6c91b8fa0a02463da34c`: larger
  Command Center screens, Key Master, illustrated weather, ten operating-system
  characters, Vault and Workshop rooms, and separate voice, dictation and music
  switches. DJ playback pauses room music and clears mute; mute pauses the DJ.
  All downstairs stairs work by walking onto them, and Kilix walks behind

  provider usage checks start in the home folder. The Command Center adds a

## Qualification

The intended fresh-install baseline and supported upgrade source are 0.2.2.
Fresh BIOS/EFI installations, update/rollback, converter/Needle end-to-end
checks and final artifact acceptance are pending. Earlier source reviews and
an earlier local candidate ISO do not qualify this combined release.
The RC7 carrier `42b6956b` was reviewed by two seats, both "ship with known
issues", listed in [the follow-ups](0.2.3-followups.md). Two seats also
reviewed RC8's carrier `62d0c800` and both say ship with known issues.
This candidate's carrier is
`a1e685776dd4cea28500813b1951f31ce304ead8fea39e7b1ec4690372e8b618`. It binds
content `e78e1cb` and licence `596ada2`; only the interface content ref moved,
and the model artifacts and licence records are RC8's. It has no seats or
acceptance receipt yet: two independent seats review it once RC9's scope is
final, and release mode refuses the voice model until then. Paradee and
`en_core_web_sm` are `image-offline-model`. Kilix 95's workflow names Kilix
`3b953489`. Image boot acceptance is not claimed.

The attached provenance record is the final artifact
acceptance record only after the artifact has passed those checks; none is
claimed by these candidate notes. Diarization quality, hardware qualification
and deferred model campaigns retain their recorded limitations. The
kilix-diarization-cpu notice licensors match the licence-record string a
receipt binds.
Installing model files does not establish provider activation or inference
quality.

The default bundle retains its original filename `default-models-0221.tar.xz`
and checksum. Its intended RC1 asset URL is not published yet.

## Known issues

- A first standalone closure selection is refused. On a standalone Debian
  machine that has never selected a Plebian-OS closure, `pleb update --to`
  stops with "could not select the split closure (status 6)": the selector
  reads its rollback record from session.env, which holds no release version
  yet. Machines that selected a closure before, including upgrades from
  0.2.2, keep that record and are not affected. Release owner decision,
  2026-11-09; see [the follow-ups](0.2.3-followups.md).
