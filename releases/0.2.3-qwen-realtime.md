# Qwen real-time measurement

The real-time requirement is a warm realtime factor below 1. That factor
is synthesis wall time divided by the duration of the audio produced.
Model load is not included. A factor of 1 is not real time.

This run used local 0.6B CustomVoice snapshot revision
`85e237c12c027371202489a0ec509ded67b5e4b5`, CPU float32, PyTorch 2.6.0+cpu,
and four threads on an Intel Core i7-9850H. The sentence was "Hello from
Kilix.", speaker Ryan, language English. One warmup run was discarded.
Three later runs were scored. Sampling followed the model default, so the
clip length changed between runs.

| Run | Audio | Synthesis | Realtime factor |
| --- | ---: | ---: | ---: |
| warmup (not scored) | 2.80 s | 26.429 s | 9.439 |
| 1 | 4.56 s | 28.561 s | 6.263 |
| 2 | 3.44 s | 22.367 s | 6.502 |
| 3 | 2.88 s | 21.693 s | 7.532 |

The requirement is not met. This note does not advertise Qwen real-time.
CUDA was not measured: that interpreter reports CUDA unavailable. This
measurement does not freeze a CPU or GPU profile and does not qualify F104.
