## Publication status

Nothing is published for 0.1.8. No artifact exists, and none of the pins here
has been through an acceptance install. The exact resolved Plebian-OS commit,
artifact hashes and acceptance result are recorded from the accepted build and
attached with the ISO. Any earlier local candidate ISO produced while 0.1.8 was
in development predates this closure: it must not be distributed, and must
never be used as release provenance.

## Install and upgrade policy

0.1.8 upgrades in place from **0.1.7**, the immediately previous published
release, preserving user files, application and game state, provider/desktop
state, shared settings, operator session choices, and custom wallpaper/layout.
No skip from an earlier release is supported: 0.1.2 to 0.1.8 is a fresh
install, and 0.1.7 remains the fresh-install baseline for anything older. The six upgrade gates in [`UPGRADING.md`](../UPGRADING.md) must be
completed against a real 0.1.7 installation, using the path documented for
installed users rather than a developer checkout, and

    ### Upgrade acceptance result

is reserved for that record. A failed or missing upgrade run blocks publication.

## Highlights so far

- **`kilix install`** — one list of everything this system can install: the
  pinned content catalog and the coding agents together, with their installed
  state, `--update`, and `--json`. The catalog half drives the desktop's own
  content module and the agent half runs each vendor's documented command,
  printing it and its documentation URL before asking to run it.
- The Kilix TUI desktop and the Kilix 95 Start menu both reach that same
  command rather than keeping catalogues of their own. Programs also gains a
  Coding Agents entry whose context menu reaches Claude Code, Codex and Kimi
  Code individually.
- Prerequisites for those agents: `nodejs`, `npm` and `ripgrep`. None of the
  three bundles ripgrep and all of them search a working tree constantly.
- Kilix 95's Start menu keeps an opened submenu open once the pointer leaves
  the row that opened it; it closes on a click outside every menu, or when
  another cascade entry replaces it.
