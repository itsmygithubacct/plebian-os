# Plebian-OS 0.1.2

Plebian-OS 0.1.2 is a coordinated release of Plebian-OS, Pleb, Kilix,
and Kilix 95, based on Debian 13.5 installer media and a pinned Debian
snapshot.

## Highlights

- Complete Plebian-OS identity across BIOS, UEFI, the graphical installer,
  LightDM, and the desktop, including the angular-P geek logo and wallpaper.
- Coordinated source checkouts under `~/.local/gpu_terminal/sources` and
  private persisted data under `~/.local/gpu_terminal`.
- A complete Kilix native dependency closure, Pleb recovery guide, serialized
  transactional updates, coherent Kilix generations, and bounded rollback
  state.
- Kilix and Kilix-95 fixes for session logging, clickable terminal chrome,
  fresh firstboot builds, and unique streamed graphics frames.

## Validation performed before publication

- Fresh 4 GiB / 20 GiB end-to-end installation using the exact coordinated
  artifact closure, followed by provenance, storage, provider, update,
  recovery, application-soak, reboot, and log checks.
- All 947 ISO media checks plus stock-content, signed-binary, deterministic
  installer-overlay, and hybrid BIOS/UEFI/MBR/GPT/APM inspection.
- BIOS and UEFI installer-menu checks with publishable-media autoboot disabled.
- Injected same-source promotion failure with restoration of the prior
  generation, stamps, repositories, OS layer, and persistence sentinels.
